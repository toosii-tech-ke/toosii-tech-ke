## About

I’m **Toosii Tech**, a developer and builder focused on useful software, automation, and reliable self-hosted tools. I enjoy turning ideas into practical products that are easy to deploy, simple to use, and built to keep improving.

My current work centers on **WhatsApp automation**, developer utilities, web tooling, and the open-source ecosystem around Node.js.

## Featured project

### [TOOSII-XD-ULTRA](https://github.com/toosii-tech-ke/TOOSII-XD-ULTRA)

A full-featured WhatsApp bot launcher designed for flexible deployment across hosting panels, VPS environments, Docker, and Termux.

- Self-updating runtime with lightweight deployment
- Multi-device WhatsApp support through Baileys
- Downloads, AI tools, media utilities, moderation, games, and more
- Designed for practical self-hosting and straightforward setup
